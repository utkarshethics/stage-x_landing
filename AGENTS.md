# Workspace Rules: stage-x.space

## Scope & Purpose
- This repository is exclusively for the **stage-x.space** landing site and summits website.
- **DO NOT** create unrelated business projects, scraping scripts, rental tools, or external automations in this repository root.

## Workspace Isolation Guidelines
- If a task involves a separate project (e.g. Masterji, rental platform, CRM automations, or general scrapers), request or open a dedicated directory on Desktop (e.g. `~/Desktop/<project-name>` or `~/Desktop/Automation/`).
- Ad-hoc test scripts or scratch files must be placed strictly in `scratch/` (which is git-ignored) so they never pollute version control or cross-contaminate sessions.
